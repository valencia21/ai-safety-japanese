# Compound

Capture learnings after completing significant work to make future development faster.

## When to Run

- After implementing features
- After fixing complex bugs
- After architectural decisions
- After discovering important patterns

## Process

1. **Reflect**: What problem did you solve? What decisions did you make? What worked/didn't work?
2. **Update Memory**: Add to `.claude/memory/decisions-made.md` or `.claude/memory/lessons-learnt.md`
3. **Update Docs**: Update `CLAUDE.md`, `README.md`, or principles if needed

## Decision Template

```markdown
## 2025-XX-XX - [Feature Name]

**Context:** [Problem being solved]
**Decision:** [What you did]
**Reasoning:** [Why this approach]
**Trade-offs:** [What you gained/lost]
```

## Lesson Template

```markdown
## 2025-XX-XX - [Lesson Title]

**What Happened:** [Situation]
**What We Learned:** [Key insight]
**How to Apply:** [When to use this]
**Example:** [Code snippet if helpful]
```

## Quick Capture

One-liner format:

```markdown
- 2025-XX-XX [Category]: [Brief lesson] - [Context]
```

## Remember

Every learning compounds - making you and Claude progressively faster. The goal is permanent knowledge that survives beyond individual memory.
