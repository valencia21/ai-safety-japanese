# Sync with Upstream 

Sync the current repository with the upstream repository 

## Workflow

- Fetch the latest updates from the `upstream` and push to `origin` 
- Rebase the current `local` branch onto the trunk branch of the `origin`

## Notes

- **Rebase conflicts**: Handle conflicts carefully during the rebase step
